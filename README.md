Keeper App
A simple, elegant note-taking application inspired by Google Keep. Designed for ease of use, persistence, and intuitive navigation.
Features
- Persistent Notes – Saves notes locally using localStorage, ensuring no data loss across sessions.
- Smart Navigation – Supports state management via query parameters, enhancing accessibility and deep linking.
- Material-UI Styling – Uses Material-UI components and animations for a polished user experience.
- Seamless Deployment – Deploy effortlessly using GitHub Pages or Vercel.
